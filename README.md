### 📌 Sobre o projeto

O **Rei das Malas** é uma aplicação web desenvolvida para apresentar os produtos de uma loja de malas e acessórios de forma moderna, organizada e intuitiva. O objetivo é oferecer ao cliente uma navegação agradável, com destaque visual para os produtos e uma experiência fluida tanto no computador quanto no celular.

O projeto foi desenvolvido em dupla como atividade acadêmica do curso de **Ciência da Computação**.

---

### ✨ Destaques

- 🛍️ Catálogo de produtos organizado em cards
- 🎨 Identidade visual consistente, com paleta de cores e tipografia definidas
- 📱 Layout responsivo, adaptado para computador e celular
- 🧭 Navegação simples e intuitiva
